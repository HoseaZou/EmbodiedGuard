# 预算检查候选版本：手动复测

此目录由原 EmbodiedGuard 隔离复制而来。原项目、自动驾驶基线和历史试验没有覆盖。启动前先确认当前 AGH 没有正在执行的任务；下面会停止该工作目录的旧后台并切换工具定义。

## 实现与限制

新增 `embodiedguard/timing.py`，在深复制的跟踪器和独立车辆状态上预测到点及停稳时间。不会执行真实运动或读取未来传感器。续跑保留路线进度，后续预测段假定使用 15 秒。未来障碍、故障和真实模型等待均未知，估计不保证到达。

规划反馈新增 execution_estimate。执行前在实际等待计入预算后读取有效传感器、重新预测；不足以支持估计行驶时间及固定 5 秒到点后余量时，返回 INSUFFICIENT_COMPLETION_BUDGET，预测不可用时返回 BUDGET_ESTIMATE_UNAVAILABLE。车辆不为这两个拒绝启动运动，Agent 仍决定有依据的下一步或安全终止。stop、verify 可用，300 秒期限和硬安全保留。

5 秒是固定准入余量，不是模型/审批耗时保证。仍可能发生运行中故障或超时，最终以 verify 为准。

模型不完整输出的问题目前只有源码诊断和提示缓解，尚未证明真实模型已修复。AGH 的 inference.ts 收到 text_delta 会累积普通文本，只有 toolcall_end 才创建调用；没有工具调用时使用 end_turn。不会从残缺文本猜参数，也未改造赛事官方 Harness。

## 1. 停止旧页面服务并启动候选版本

在原来运行 serve 的 PowerShell 按 Ctrl+C，保留已有试验记录。随后在 Windows PowerShell 执行：

```powershell
& '<competition-workspace>\EmbodiedGuard-next\scripts\activate-candidate.ps1'
```

官方 CLI 的配置更新和信任提示分别输入 y。它们只授权这八个工具定义；会话里的工具审批仍要单独处理。若脚本被 PowerShell 执行策略拒绝，把错误发给 Codex，不修改系统全局策略。

保持终端打开。出现端口或 origin 错误时不要提交任务，先发送错误。页面为 <http://127.0.0.1:8788/>。

## 2. 只读确认新工作进程

另开 PowerShell：

```powershell
Get-CimInstance Win32_Process |
    Where-Object { $_.Name -eq 'python.exe' -and $_.CommandLine -like '*EmbodiedGuard-next/run_mcp.py*' } |
    Select-Object ProcessId,CommandLine | Format-List
```

应只有一个候选工作进程，参数包含 `--scenario stale`，输出目录位于 `EmbodiedGuard-next/outputs/agh-session`。如果仍是旧路径或有多个候选工作进程，停止在此步骤。

AGH 会话工作目录仍用 `<competition-workspace>\EmbodiedGuard`，工具入口已经指向候选版本。不要让模型编辑该工作目录。

## 3. 新会话，提示只发一次

```powershell
Get-Content -LiteralPath '<competition-workspace>\EmbodiedGuard-next\prompts\inspection.md' -Raw -Encoding UTF8 | Set-Clipboard
```

新建 AGH 会话，沿用 agnes-3.0-flash，粘贴发送。仅对 observe、plan_route、execute_route、inspect、reobserve、wait、stop、verify 选择本会话允许。其他工具不批准，不开全访问或永久权限。

不要在 AGH 运行中追加留证表或“继续”。模型结束且没有 verify 就保留为未闭环；不要人工推动后标为自主恢复通过。留证模板只发给 Codex。

首次 observe 应 frame=0、原点、静止、目标为空、未终止。首次规划反馈应包含 execution_estimate，这同时确认运行的是候选代码。

## 4. 发回结果

```text
会话完整地址：
开始/结束时间（未知则写未知）：
首条规划是否含 execution_estimate：
是否只发送了一个提示：
模型是否在故障后自行继续调用工具：
是否出现 INSUFFICIENT_COMPLETION_BUDGET / BUDGET_ESTIMATE_UNAVAILABLE：
verify 完整返回（无则写未调用）：
最终回复全文：
审批超时/拒绝及其他错误：
```

结束后先不要重启或删除输出，便于绑定会话证据。安全终止可以证明拒绝和停稳链路生效，但不能作为巡检成功。该单次合成二维运动学试验不证明真实机器人性能或成功率提升。
